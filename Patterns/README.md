# Pattern 1 – Square Pattern

[Problem Link – Square Pattern](https://www.geeksforgeeks.org/problems/square-pattern/1)

Geek is very fond of patterns. Once, his teacher gave him a square pattern to solve. He gave Geek an integer `n` and asked him to build a pattern.

Help Geek to build a square pattern with the help of `*` such that each `*` is space-separated in each line.

### Your Task:
You don't need to input anything. Complete the function `printSquare()` which takes an integer `n` as the input parameter and prints the pattern.

### Time & Space Complexity:
- Time Complexity: O(n²)
- Space Complexity: O(1)

### Constraints:
1 <= n <= 1000
